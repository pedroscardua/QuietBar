First public open-source edition of QuietBar: native macOS noise mixer with a compact menu bar popover, ten layers, presets, gentle movement and sleep timer.

This edition includes original generated noise, not myNoise recordings. Importing myNoise settings does not reproduce its sound. Preferences use a separate QuietBar-OpenSource directory.

The archive is for Apple Silicon. Runtime deployment target is macOS 13+; tested on macOS 26. Builds are ad-hoc signed, not Apple-notarized, so downloaded apps may be blocked by macOS. Building from source is recommended. Intel users can build from source.

SHA256SUMS.txt contains the archive checksum. Unzip and move the entire QuietBar.app into Applications. Quit any existing QuietBar instance first. The interface is in Brazilian Portuguese.

Validation: silent tests cover generated audio, sample-reference mixing, stream stability, state, timers and hidden panel layout. Listening, real menu clicks, VoiceOver and macOS 13–25 remain manual checks.
