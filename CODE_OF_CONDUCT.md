# Community conduct

Treat contributors with respect. Welcome newcomers and different levels of experience. Keep feedback focused on code and behavior. Harassment, threats, discriminatory language, sexual harassment and publication of private information are unacceptable.

This applies to issues, pull requests, discussions and other project-managed spaces. Maintainers may edit or remove harmful content, lock conversations, or restrict participation. Serious or repeated violations may result in a ban. Decisions should be proportional and protect affected participants.

Report abusive GitHub content through GitHub's **Report content** action; do not repeat private information in a public issue. For non-sensitive process questions, contact the maintainer through a project issue. Do not use security advisories for conduct reports.
